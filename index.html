Seeing, in letters

Syzygy is a tiny program that turns a camera frame into readable text — Braille dots, edge marks, and tone characters — in one fast pass, producing exactly the same output on every machine.

Because the world arrives as text, a small text model can learn to see through it.

And each model learns exactly one camera's one job — nothing more — so it stays small enough to run almost anywhere.

Try the kernel right now

The kernel itself runs in your browser, on your own camera if you allow it — nothing leaves your device: the live Syzygy demo. The full source is public: SuperInstance/Syzygy on GitHub.

Where to go next

Watch it play

A model reads a game's letter-grid and plays it, steered by strategy tiles you can swap mid-game. Seeing become doing, with the honest timings printed on the exhibit.

Learn, at your level

Three tracks: the curious (plain language, no jargon), builders (clone it, run it, write a strategy tile), and agents (a tutorial written for a model learning to read a text frame — procedures and measured baselines included).

What it's for

One camera, one job: the harbor inventory walker, the warehouse forklift, the packing grabber, and the overseer that joins many first-person views into one map.

Super, not artificial. You are not handing over the captain role — you are hiring more crew.

SuperInstance was designed while commercial fishing, on the model of a vessel: crew aboard, equipment aboard, and a captain who is responsible for everything. Expertise can be hired — architects, welders, shipfitters — but the application, and the responsibility, stay with the captain. These systems are built to be crew.
